# 🚀 Logistic Regression Binary Classification

## 📌 Project Overview
This project focuses on building a robust binary classification model using Logistic Regression. It demonstrates the complete machine learning workflow — from data preprocessing to model evaluation — using real-world dataset inputs.

---

## 🎯 Objective
To develop a Logistic Regression model capable of accurately predicting binary outcomes and evaluating its performance using standard classification metrics.

---

## 🛠️ Tech Stack
- Python 🐍
- Pandas & NumPy
- Scikit-learn
- Matplotlib

---

## ⚙️ Workflow

1. Data Loading  
   - Dataset uploaded and inspected  

2. Data Preprocessing  
   - Missing values handled  
   - Categorical variables encoded  

3. Feature Engineering  
   - Features and target variable separated  

4. Model Training  
   - Logistic Regression model applied  

5. Model Evaluation  
   - Confusion Matrix  
   - Precision & Recall  
   - ROC-AUC Score  
   - ROC Curve Visualization  

---

## 📊 Key Concepts Used

- Binary Classification  
- Logistic Regression  
- Sigmoid Function  
- Threshold Tuning  
- Model Evaluation Metrics  

---

## 📈 Results & Insights

- The model successfully classifies binary outcomes.  
- ROC-AUC score indicates strong model performance.  
- Precision and Recall provide a balanced evaluation of prediction quality.  
- ROC curve shows good separability between classes.  

---

## 🧠 Conclusion

The Logistic Regression model proved to be an effective approach for binary classification. With proper preprocessing and evaluation, the model delivers reliable predictions and demonstrates strong performance across multiple evaluation metrics.
